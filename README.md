# 亲情接听助手

> 帮爸妈轻松接微信电话：语音播报来电人 + 家人来电自动接通。
> 应用**不显示自己的界面**，只做两件事：听出微信来电、替你按下微信里真正的接听键。

---

## 功能一览

| 功能 | 说明 |
|------|------|
| **语音播报（用 App 里的称呼）** | 微信来电时大声播报「大儿子来视频电话了，点屏幕上圈出的绿色按钮接听」，一直播到接通/挂断为止。播报的是你在 App 里给家人设的称呼（如"大儿子"），不是微信昵称 |
| **播报文案可自定义** | 「设置 → 语音播报文案」里，App 说的每一句话都能改成你自己的说法（含家人熟悉的方言措辞）。支持 `{称呼}` `{类型}` `{秒数}` 占位符，每条都能单独试听、单独恢复默认 |
| **屏幕指引** | 在微信那个绿色接听键上套一个醒目的绿色圆圈 + 「点这里接听」箭头，老人一眼就知道点哪。圆圈不挡操作，点在圈上等同于点微信按钮 |
| **家人自动接听** | 名单里勾选「自动接听」的家人来电，响铃 N 秒（默认 8 秒）后自动接通，老人什么都不用碰 |
| **全自动，不需要老人操作** | 自动接听时会**主动把微信来电界面拉到最前**（通知跳转 → 下拉通知栏 → 启动微信），无论当时屏幕上只有一条通知、还是顶部横幅，都会先把接听键弄出来再点。全程不需要老人动手 |
| **自动点接听** | 应用通过无障碍服务自动帮老人点掉微信里那个没有文字的小图标（四级定位：文字 → 位置 → 左右镜像 → 比例坐标；定位时自动扣除底部导航栏高度） |
| **有语音就不响铃** | 语音播报和铃声二选一，绝不叠加。本版本已**彻底去掉铃声兜底**——微信来电本身就有铃声，我们再响一遍只会盖住播报、白吵老人 |
| **随时能停** | 通知上和屏幕浮层上各有一个「停止提醒」按钮，任何时候点一下就彻底安静 |
| **接通/挂断自动停** | 检测到接通、对方挂断、来电取消、通知消失、界面消失，任一命中就立刻停掉语音与震动 |
| **震动提醒** | 来电时持续震动，听力不好的老人也能感知 |
| **来电通知** | 锁屏时点亮屏幕，并能一键进入微信通话界面 |
| **运行记录** | 「设置 → 查看运行记录」把每次来电的判断过程摊开：收没收到通知、在不在名单、点击结果、什么时候停的声音 |

> ⚠️ 为什么没有「接听大按钮」界面了？
> 早期版本会在来电时弹出一个我们自己的全屏大按钮界面。但那个按钮是假的——按下后还得靠代码去点微信里的真按钮，
> 老人容易误以为「按了没用」；锁屏时它还会和微信界面叠在一起。
> v1.8 起整体去掉，老人面对的就是**微信真实的来电界面**，只有那一个接听键是真的。

## 安装方式

### 方式一：直接安装 APK（最快）

把 `亲情接听助手-vX.Y.apk` 传到老人手机，点击安装。

> 若提示「未知来源应用」，请在 设置 → 安全 → 允许安装未知应用 中授权。

### 方式二：用 Android Studio 打开工程

工程目录 `app/src/main/` 下是标准 Android 项目结构，可直接用 Android Studio 打开编译。

### 方式三：命令行手工构建（无需 Gradle）

```bash
# 需要 JDK 17+、Android build-tools 34、android-34 platform
BT=/path/to/build-tools/34.0.0 JAR=/path/to/android.jar bash tools/build_apk.sh
```

## 安装后必做：四步权限设置

打开「亲情接听助手」App，按提示完成以下设置（**缺一不可**）：

### 第一步：通知使用权
- 点击「去开启」→ 在系统列表里找到「亲情接听助手」→ 打开开关
- **作用**：监听微信的来电通知，提取来电人姓名

### 第二步：无障碍服务
- 点击「去开启」→ 在列表里找到「微信来电自动接听（亲情接听助手）」→ 打开开关
- **作用**：这是自动点击微信接听键的**前提**，家人来电自动接通也依赖它

### 第三步：显示在其他应用上层（安卓 10+）
- 点击「去开启」→ 允许本应用显示在其他应用上层
- **作用**：两个用途 —— ① 来电时**在屏幕最上层画出绿色圆圈指引**，套在微信接听键上告诉老人点哪里；
  ② 把**微信的通话界面**调到最前面，让自动点击能落到微信上
- 这个圆圈**不接收触摸**，点它会直接穿透到下面的微信，等同于点微信的按钮；圈上另有一个「停止提醒」小按钮可点
- 若不给这项权限：屏幕上不会出现圆圈指引，锁屏来电时自动接听也更容易失败（失败时会改用语音提醒老人自己点）

### 第四步：锁屏全屏通知（安卓 10+）
- 点击「去开启」→ 在系统「全屏通知」列表里，**同时把「亲情接听助手」和「微信」都打开**
- **作用**：锁屏来电也能点亮屏幕，并让微信通话界面被拉起来

### 额外一步：后台保活（重要！）
- 点击「去设置自启动/后台运行」→ 按手机品牌找到对应设置项
- **作用**：防止系统杀后台，导致来电时 App 没反应

| 品牌 | 设置路径 |
|------|----------|
| **小米 / Redmi** | 设置 → 应用设置 → 授权管理 → 自启动管理 → 开启本应用 |
| **华为 / 荣耀** | 设置 → 应用和服务 → 应用启动管理 → 关闭「自动管理」→ 手动开启「允许自启动」「允许后台活动」 |
| **OPPO / 一加 / realme** | 设置 → 电池 → 应用耗电管理 → 允许完全后台行为 + 允许自启动 |
| **vivo / iQOO** | 设置 → 电池 → 后台耗电管理 → 允许后台高耗电 |
| **三星** | 设置 → 电池 → 后台使用限制 → 不优化本应用 |
| **其他** | 设置 → 应用 → 本应用 → 电池 → 无限制 / 允许后台运行 |

## 使用说明

### 1. 添加家人名单
- 在设置页「称呼」里填老人熟悉的叫法，如「大儿子」「闺女」
- 「微信备注名或手机号」**填对很关键**：填微信来电通知里显示的那个昵称 / 备注 / 微信号（例如微信里显示「hh」就填 hh）。只有填对了，App 才能把来电匹配到这位家人，并用你设的「称呼」来播报；没填或填错，就会直接播报微信原始的昵称
- 点击「＋ 添加到家人名单」
- 勾选「自动接听」的家人来电会自动接通（默认等待 8 秒，可改）

### 2. 试听效果
- 点击「▶ 试听：语音播报 + 屏幕指引（模拟张三来电）」
- 手机会播报「张三来视频电话了，想接就点屏幕上圈出的绿色按钮…」，并短震一下
- 同时屏幕上会出现来电时的**指引浮层**（绿色圆圈 + 「点这里接听」+ 顶部「停止提醒」按钮），
  7 秒后自动消失，方便先看看效果再决定要不要用
- 这是纯演示，不会真的拨出电话，也不会做任何接听动作
- **没听到声音？** 语音播报依赖手机的中文 TTS 引擎。按钮下方的状态卡会直接显示检测结果：
  - 绿色「✓ 语音播报正常」= 一切就绪
  - 红色「✗ …」= 会写明原因（没连上引擎 / 引擎读不出中文）和修复路径，下面还有「检测情况」列出识别到的引擎
  - 可点「↻ 重新检测语音播报」在系统里改完设置后重新判定

### 3. 真实来电时的体验
1. 微信来电 → 手机震动 + 大声播报「XXX 来视频电话了…」
2. 屏幕亮起，显示的是**微信自己的来电界面**（本应用不弹任何自己的界面）；
   如果当时屏幕上只有一条通知或顶部横幅，App 会**自动把它拉成全屏来电界面**
3. 屏幕上会出现指引浮层：绿色圆圈正好套在微信那个绿色接听键上，上方有「点这里接听」的箭头
4. 如果是名单里的家人且勾选了「自动接听」：等待 8 秒后**全自动接通**
   （App 自己拉起微信界面 + 自己点接听，老人全程不用碰手机）
   - 自动点击期间圆圈**仍然画着**：万一自动化没成功，老人顺手点一下绿圈也能接
   - 若最终确实没接上，语音会改成「没能自动接听，请点屏幕上圈出的绿色接听按钮…」
5. 其他来电：老人在绿色圆圈里点一下即可（等同于点微信的按钮）；
   播报会一直念到接通或挂断，**接通、挂断、取消都会立刻停**
6. 嫌吵？屏幕顶部和通知上都有「停止提醒」，点一下立刻安静

### 4. 圈的位置不准？自己校准一次（每台手机只做一次）
微信那个绿色接听按钮是**纯图标**，不同机型、不同微信版本、甚至同一台手机换导航方式，
它在屏幕上的位置都会变。App 内置的是按 1220×2712 真机截图量出来的默认位置
（横向 80.3%、距底部 11.4%），多数手机够准，但没法保证每一台都准 —— 所以干脆让你自己指一下。

**怎么校准：**
1. 进「设置 → ◎ 校准接听键位置」，会自动退回桌面，屏幕上出现一个绿圈
   （它浮在所有应用之上，包括微信来电界面）
2. 让家人给你打个微信语音/视频电话，看到微信那个绿色接听按钮后，
   **按住圆圈左边的灰色小球拖动**，把绿圈套到按钮上
3. 拖不准还能用顶部「← ↑ ↓ →」一格一格微调，用「圈大 / 圈小」改圆圈大小
4. 点「✓ 保存这个位置」

调好之后，**屏幕指引画的圈**和**自动接听真正点下去的点**会一起变准 —— 两者共用同一个坐标。
设置页会显示当前用的是默认位置还是你自己调过的位置；不想用了点「恢复默认」即可。
忘了关也没关系：5 分钟后校准浮层会自动收起。

### 5. 改成你家人习惯的说法（语音文案自定义）
- 进「设置 → 🗣 语音播报文案」
- 8 条文案都能改，例如把开头改成奶奶听得最顺的「你外孙女找你说话啦」
- 文案里可以放占位符，App 会自动替换：
  | 占位符 | 会变成 |
  |---|---|
  | `{称呼}` | 你给这位家人设的称呼（如「丈母娘」）；不在名单里时是微信显示的名字 |
  | `{类型}` | 「视频」或「语音」 |
  | `{秒数}` | 自动接听倒计时剩余秒数 |
- 每条都有「试听」和「恢复默认」；底部还能「全部恢复默认」
- 改完即时生效，下次来电就用新文案

## 它是怎么做到「自动接听」的

1. **听出有来电**：两条独立通道，任一条生效即可
   - 通知监听：读取微信的来电通知（「hh 邀请你视频通话」这种）
   - 无障碍：直接扫描微信界面，看到「邀请你…通话」就认为是来电
2. **确认要不要自动接**：来电人命中家人名单 **且** 该联系人开了自动接听 **且** 总开关已打开
   —— 三个条件缺一不可，缺哪一条都会写进「运行记录」
3. **不等判定，直接拉起 + 直接点（全自动）**：微信来电在手机上会有三种形态——
   - **全屏来电界面**：整屏的「邀请你视频通话」+ 左下红 / 右下绿两个圆钮 → **这里有接听键**
   - **通知栏里的来电通知** → 屏幕上没有接听键
   - **屏幕顶部的横幅通知（heads-up）** → 屏幕上也没有接听键

   后两种形态如果直接按比例点右下角，等于在通知栏 / 桌面上乱点：接不到电话，还可能点到别的东西。
   早期版本的做法是"先确认是不是全屏，不是就放弃"——但微信界面常常是**整页自绘、
   无障碍一个节点都读不到**，或者个别 ROM 不给窗口尺寸，这时"确认"永远失败，
   结果就是**从头到尾一次都不点**，本质还是半自动。

   现在改为**主动出击**：每一轮（约 1.2 秒）
   ① 先看是不是已经接通，是就收工；
   ② 主动把微信来电界面拉到最前（通知跳转 → 下拉通知栏 → 启动微信，依次尝试）；
   ③ **无论判定结果如何都尝试点一次接听键**。
   点击本身有多重安全网（见下），所以敢在每轮都点；点完会校验是否真的接通，
   没接上就继续下一轮（最多 8 轮，另有看门狗兜底），直到接通 / 挂断 / 超时。
   这样即使界面识别失灵，也仍然有机会点到那个按钮——老人全程不用碰手机。
4. **按下真正那个接听键**：这一步最容易失败，因为**微信的接听键是一张图，没有文字**。
   实测微信视频来电界面暴露给系统的文字只有「隐藏 / 邀请你视频通话 / 翻转 / 模糊背景 / 摄像头已开」，
   底部那个绿色圆钮既没有文字也没有描述。所以采用四级定位：
   | 级别 | 做法 | 适用 |
   |------|------|------|
   | ① 语义 | 找文字/描述为「接听 / Answer」的节点 | 少数带文字的界面 |
   | ② 几何 | 找屏幕右下方那个可点击的圆形按钮 | 接听键是无文字图标的界面 |
   | ③ 镜像 | 只找到左边那个红色挂断键时，按左右对称推出接听键位置 | 界面只暴露了挂断键 |
   | ④ 比例 | 按屏幕百分比坐标点（见下） | 界面完全自绘、节点为空 |

   **比例坐标怎么来的**：把真机截图（1220 × 2712）做像素分析，找出底部两个圆钮的中心——
   红色挂断键在 (240, 2403)，绿色接听键在 (980, 2403)（界面左右对称）。换成百分比就是：

   | 项 | 从左算 | 距底部算 |
   |---|---|---|
   | 接听键中心 | 80.3% 屏宽 | 11.4% 屏高 |
   | 挂断键中心 | 19.7% 屏宽 | 11.4% 屏高 |

   这样不管什么品牌、什么尺寸、什么分辨率的手机，都能算出同一个位置，
   不需要为每种机型单独适配。**有虚拟导航栏（三键 / 手势条）的手机，定位时会自动扣除导航栏高度**——
   否则算出的点会落到导航栏的空白区（按钮半径约 109px，而三键导航栏高约 144px，不扣就会偏出按钮）。
   若界面上能读到「摄像头已开 / 模糊背景」这类同列按钮，
   还会用它们的横坐标覆盖那个 80.3%，进一步校准。**屏幕指引画的圈和实际点的位置用的是同一套坐标**，
   所以"圈在哪就点哪"，不会出现圈一个地方点另一个地方。
5. **点完必须验证**：点一次后会检查「是否进入通话中 / 是否还在响铃」，没成功就再试；
   坐标兜底因无法确认点了什么，**整通来电只允许盲点一次**（避免重复点碰到挂断键），
   之后即使继续重试也只做精确点击。
6. **失败要吭声**：以上都没成功，就语音 + 震动 + 重新显示屏幕指引，让老人自己点。
   注意：自动接听进行期间**指引圈也是画着的**，所以万一自动化失灵，
   老人顺手点一下那个绿圈就行，不会错过电话。

### 声音是怎么停下来的（五个独立信号，任一命中即停）

来电提醒最怕"停不下来"。所以停止条件做了五重冗余，任何一条生效就立刻静音：

| # | 信号 | 覆盖的场景 |
|---|------|-----------|
| ① | 无障碍看到微信「通话中」界面（出现静音/免提） | 正常接通 |
| ② | 系统音频进入通话状态（且无障碍没看到还在响铃） | 无障碍读不到界面时也能判断接通 |
| ③ | **微信来电通知被移除** | 对方挂断 / 自己接听 / 对方取消——微信在这三种情况下都是直接撤掉通知，不改文字 |
| ④ | 微信来电界面从屏幕上消失（连续 3 次确认） | 上面两条都没拿到时的兜底 |
| ⑤ | 用户点「停止提醒」 | 单纯嫌吵，想立刻安静 |
| ⑥ | 提醒持续满 90 秒 | 极限兜底，不让它无限吵下去 |

## 常见问题排查

### Q1：来电时没有语音播报
- 检查「通知使用权」是否已开启
- 打开设置页看语音状态卡：红色说明引擎有问题，按提示去「文字转语音」里选择或安装中文引擎，回来后点「↻ 重新检测语音播报」
- 调高「媒体音量」（播报走的是媒体音量通道）
- 如果手机确实没有可用的中文 TTS，App **不会**改用铃声（微信来电本身就在响铃，
  再叠一层只会更吵、还会盖住播报），而是靠**震动 + 屏幕指引**提醒。
  要恢复语音，请按状态卡提示去装一个中文语音引擎。
- 老旧机型首次播报可能延迟 1 秒左右（语音引擎需要加载），属正常现象

### Q2：来电时没有自动接听
**先看「设置 → 📋 查看运行记录」**，最后几行会直接说明卡在哪一步：
- 完全没有 `[通知]` 记录 → 通知使用权没开，或微信这条通知没被系统交给本应用
- 有 `[通知] 与通话有关但未认定为来电邀请` → 通知话术与预期不符（请把这一行反馈给我们）
- 有 `[来电] … 只播报：这个人不在家人名单里` → 把来电人加进家人名单
- 有 `[来电] … 只播报：该联系人的「自动接听」没打开` → 进家人详情打开
- 有 `[来电] … 只播报：设置页的「自动接听」总开关没打开` → 打开该开关
- 有 `[接听] 无障碍服务未开启，无法自动接听` → 无障碍权限没开
- 有 `[来电] … 名单命中=无` → **名字对不上**（最常见）。这一行后面会直接把「微信显示什么、
  你配置的是什么、归一化后差在哪」列出来，照着改「微信备注名」即可
- 有 `[接听] 拿不到微信界面…按屏幕比例盲点接听键` → 微信界面没暴露任何节点，已用比例坐标兜底
- 有 `[接听] 只找到左下角的挂断键，按左右对称推算接听键` → 已用镜像法定位
- 有 `[接听] 锁屏=true` → 锁屏状态下模拟点击常被系统拦下，建议用「全屏通知」让屏幕亮起
- 有 `[会话] 电话通知消失但微信界面仍在响铃 → 判定为通知被替换，会话继续` → 正常现象，
  说明微信只是刷新了通知（以前这里会误判成挂断、导致自动接听再也不触发，现已修复）
- 有 `[接听] 点击链 11 秒内没有结论 → 看门狗接管` → 内层点击链被阻塞，已由看门狗接力重试
- 有 `[指引] 没有「显示在其他应用上层」权限` → 屏幕指引没显示出来（不影响自动接听）

其他常规检查：
- 「无障碍服务」是否已开启（自动点击的前提）
- 「显示在其他应用上层」是否已开启——锁屏时它决定微信界面能否被调到前台，也决定屏幕指引能否显示
- 是否被系统杀后台：参考上文「后台保活」设置
- 若自动点击确实失败，App 会语音 + 震动 + 重新显示绿色圆圈指引，让老人自己点

### Q3：微信没接通（提示「没接上」）
- 见 Q2：先看「运行记录」，`[接听]` 开头那几行会写清每次点击的结果
- 微信版本更新后界面可能变化，导致自动点击失效。此时屏幕指引和语音会继续提醒老人手动点
- 如果频繁失效，请把「运行记录」里的内容（点「复制全部」）连同微信版本号一起反馈

### Q4：家人来电没有自动接听
自动接听需要**三个条件同时满足**（设置页底部有一块「接不到电话时看这里」，会直接把结论写在上面）：
- 该家人已添加到名单，并且进详情勾选了「自动接听」
- 设置页的「开启自动接听」总开关已打开
- 「自动接听前等待秒数」不要太长（默认 8 秒）

**最常见的坑：名字对不上。** 运行记录里如果出现
`名单命中=无`，说明微信显示的名字和你填的「微信备注名」不一致。
记录里会直接把两边**归一化之后**的样子并排列出来，例如：

```
微信显示「hh 」→ 归一化「hh」；名单里能比的是：「丈母娘」(备注=ｈｈ→hh)
```

一眼就能看出是差在空格、全角/半角，还是名字真的不同。
App 已经会**自动忽略空格、大小写、全角半角与常见标点**再比一次，
所以只要不是真的换了名字，一般都能匹配上。
若确实对不上，请把微信里显示的名字原样填进这位家人的「微信备注名」。

### Q5：电话已经接起来了，App 还在提示 / 还在播报（v1.16 已修）
这是 v1.16 之前的一个真实 bug：**接通之后界面上仍然挂着「挂断」按钮**，
而旧版本只要看到「挂断」就认为"还在响铃"，于是把同一通电话当成新来电，
每隔两秒重新开一次提醒会话 —— 表现就是"接都接起来了，还在念、还在画圈"。

v1.16 起改成：
- 「挂断」不再作为"正在响铃"的证据（只有「邀请你…」和「接听」才算）；
- 判断界面状态时**先判「是不是已接通」，再判「是不是在响铃」**；
- 再加一道兜底：刚接通/刚结束后 30 秒内，如果微信仍显示通话中，
  任何"新来电"判定都会被忽略，运行记录里会写
  `[来电] 忽略这次来电判定：上一通刚刚接通/结束…`

如果升级后仍有这个现象，请把「运行记录」里 `[无障碍]` 和 `[来电]` 开头的几行发过来 ——
那几行会写清当时界面上读到了哪些文字，能直接看出是哪种界面被认错了。

### Q6：屏幕上的绿圈没套在接听按钮上（偏了）
- 直接按上一节「4. 圈的位置不准？自己校准一次」调一次就好，调完**圈和自动点击一起变准**
- **对齐的客观标准**：让绿色按钮中间那个**白色电话图标落在圈的正中心**。
  图标必然在按钮圆心，比凭肉眼感觉对齐可靠得多
- 校准时圈的把手在圆圈**左边**（一个灰色小球），是故意的：把手要是压在圆圈上，
  就会挡住微信的接听键，自动接听反而点不中
- 拖乱了点「回到当前」可以退回；点「回到默认」恢复内置位置
- 校准进行中不会再画来电指引圈（避免两套圈叠在一起看不清），校准完自动恢复
- 如果你不想自己拖：把微信来电时的**整屏截图**发出来，我可以按截图量出准确比例，
  直接帮你改进内置默认值

### Q6b：只想听语音，屏幕上什么都不想显示
「设置 → 来电提醒方式」里有三个独立开关，全部关掉即可：
| 开关 | 关掉后 |
|---|---|
| 显示绿色圆圈 | 不再画那个圈（它浮在微信上面，关掉还能减少对界面识别的干扰） |
| 显示顶部文字提示 | 不再显示「谁打来的 / 还有几秒」那条 |
| 显示「停止提醒」按钮 | 不再显示顶部那个黑按钮 |

**三个全关 = 屏幕上干干净净，只有语音播报**，连悬浮窗权限都不需要了。
改动时 App 会立刻用一句话告诉你"现在到底会显示什么"，不会出现搞不清组合效果的情况。

### Q7：挂断后声音停不下来 / 太吵想关掉
本版本做了五重自动停止 + 一个手动开关，正常不会有停不下来的情况：
- **自动停**：接通、对方挂断、来电取消、通知被移除、界面消失、满 90 秒，任一命中立刻静音
- **手动停**：来电时屏幕顶部有个黑色「✕ 停止提醒」按钮，通知上也有一个「停止提醒」，点一下立刻安静
- 如果还有停不下来的情况，请看「运行记录」最后几行：那里会写明是哪一个信号生效、什么时候停的
  （例如 `[会话] 结束提醒（微信来电通知已消失）` 或 `[会话] 通话已接通（系统音频已进入通话状态）`）

### Q8：播报和铃声会不会一起响？
不会，而且本版本**彻底去掉了铃声兜底**。原因：
- 微信来电时**它自己的铃声本来就在响**，我们再叠一层只会更吵，还会盖住我们想播报的内容
- 所以策略很简单：能语音就只播报；语音引擎不可用时改用**震动 + 屏幕指引**，
  绝不额外响铃
- 如果你连微信的铃声也嫌吵，那是微信设置里的事（微信 → 我 → 设置 → 新消息通知）

### Q9：App 耗电吗？
- 非常低。通知监听和无障碍服务只在微信来电时工作，平时几乎不耗电
- 如果担心，可在「后台保活」设置里把电池优化设为「不优化」

## 已知限制

1. **仅支持安卓手机**。iPhone（iOS）系统封闭，第三方无法监听微信来电、无法模拟点击接听，因此无法做类似 App。iPhone 用户建议：
   - 开启 设置 → 辅助功能 → 音频/视觉 → LED 闪烁提醒
   - 把微信字体调到最大（设置 → 通用 → 辅助功能 → 更大字体）
   - 家人尽量改用系统电话拨打老人手机
   - 如果条件允许，给老人换一台安卓机使用本方案

2. **微信版本适配**。微信不同版本的通话界面差别不小，尤其是**接听键常常只是一个没有文字的图标**。
   我们做了「文字 → 按钮位置 → 左右镜像 → 比例坐标」四级定位，并已自动扣除导航栏高度、对不同来电形态（全屏 / 通知栏 / 横幅）分别处理，但无法保证 100% 适配所有版本。
   一旦失效，请到「设置 → 查看运行记录」复制内容反馈，那里的 `[界面结构]` 一行会记录
   微信到底向系统暴露了哪些文字和按钮——据此可以很快定位并适配。

3. **需要一定动手能力**。首次安装需要在老人手机上开启 3~4 个系统权限，建议子女亲自操作或远程视频指导。

4. **家人自动接听有风险**。自动接听意味着任何在名单里且名字匹配的人来电都会自动接通。请确保名单只放真正的家人，并设置合理的等待秒数（建议 ≥5 秒，给老人留出手动挂断的时间）。

## 隐私声明

- **不上传任何数据**。所有功能都在手机本地运行，不联网、不上传通话记录、不上传通讯录。
- **只读取微信通知文本**。通知监听仅用于识别「邀请你视频/语音通话」这类来电通知，提取来电人姓名用于播报和匹配名单。
- **无障碍服务仅用于点击接听**。不会读取微信聊天内容，也不会操作微信的其他功能。

## 技术原理（给开发者看）

```
微信来电
  ├─ 通知监听服务 (NotificationListenerService)
  │     └─ 解析通知里的「来电人 + 通话类型」
  │     └─ 触发 CallSessionManager.startCall()
  │
  └─ 无障碍服务 (AccessibilityService)
        └─ 监听微信窗口状态变化（只监听 com.tencent.mm）
        └─ 发现「邀请你…通话」→ 确认是来电界面
        └─ 提供 answerCall() 自动点击能力（四级定位，含导航栏扣减）
        └─ 每次点击前校验当前窗口属于微信，避免点到别的应用

CallSessionManager（本应用不显示任何界面）
  ├─ TTS 语音播报（循环，用 App 里配置的称呼；文案取自 SpeakScript，全部可自定义）
  ├─ 震动
  ├─ 高优先级通知 → 锁屏亮屏 + 一键进微信通话界面
  ├─ 名单命中 + 自动接听开关 → 倒计时后 performAccept()
  │     └─ ensureFullScreen（每轮）：拉起微信来电页（通知跳转/下拉通知栏/启动微信）
  │     └─ 同轮直接 WeChatClicker.answerWithRetry(8 次 × 800ms)
  │           └─ 四级定位（文字 → 几何 → 镜像 → 比例，扣导航栏）
  │           └─ 每轮都点；点完校验是否接通，没接上就下一轮（最多 8 轮 + 看门狗）
  │           └─ 全部失败 → onAcceptFailed()：震动 + 重新显示指引 + 播报（不再响铃）
  └─ 超时/接通/挂断/通知消失/界面消失 → 清理一切
        └─ 通知消失会先延时 2.5 秒二次确认：界面还在响铃就只是被替换，会话继续
```
