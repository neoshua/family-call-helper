# 亲情接听助手

> 帮爸妈轻松接微信电话：语音播报来电人 + 家人来电自动接通。
> 应用**不显示自己的界面**，只做两件事：听出微信来电、替你按下微信里真正的接听键。

---

## 功能一览

| 功能 | 说明 |
|------|------|
| **语音播报** | 微信来电时大声播报：「大儿子来视频电话了，请点微信上的接听」，循环播报直到接通或挂断 |
| **家人自动接听** | 名单里勾选「自动接听」的家人来电，响铃 N 秒（默认 8 秒）后自动接通，老人什么都不用碰 |
| **自动点接听** | 应用通过无障碍服务自动帮老人点掉微信里那个小小的接听键 |
| **没点成功会提醒** | 万一微信界面没能到前台、点不到接听键，立刻响铃 + 震动 + 语音：「没接上，请自己点一下接听」 |
| **震动提醒** | 来电时持续震动，听力不好的老人也能感知 |
| **来电通知** | 锁屏时点亮屏幕，并能一键进入微信通话界面 |

> ⚠️ 为什么没有「接听大按钮」界面了？
> 早期版本会在来电时弹出一个我们自己的全屏大按钮界面。但那个按钮是假的——按下后还得靠代码去点微信里的真按钮，
> 老人容易误以为「按了没用」；锁屏时它还会和微信界面叠在一起。
> v1.8 起整体去掉，老人面对的就是**微信真实的来电界面**，只有那一个接听键是真的。

## 安装方式

### 方式一：直接安装 APK（最快）

把 `亲情接听助手-vX.Y.apk` 传到老人手机，点击安装。

> 若提示「未知来源应用」，请在 设置 → 安全 → 允许安装未知应用 中授权。

### 方式二：用 Android Studio 打开工程

工程目录 `app/src/main/` 下是标准 Android 项目结构，可直接用 Android Studio 打开编译。

### 方式三：命令行手工构建（无需 Gradle）

```bash
# 需要 JDK 17+、Android build-tools 34、android-34 platform
BT=/path/to/build-tools/34.0.0 JAR=/path/to/android.jar bash tools/build_apk.sh
```

## 安装后必做：四步权限设置

打开「亲情接听助手」App，按提示完成以下设置（**缺一不可**）：

### 第一步：通知使用权
- 点击「去开启」→ 在系统列表里找到「亲情接听助手」→ 打开开关
- **作用**：监听微信的来电通知，提取来电人姓名

### 第二步：无障碍服务
- 点击「去开启」→ 在列表里找到「微信来电自动接听（亲情接听助手）」→ 打开开关
- **作用**：这是自动点击微信接听键的**前提**，家人来电自动接通也依赖它

### 第三步：显示在其他应用上层（安卓 10+）
- 点击「去开启」→ 允许本应用显示在其他应用上层
- **作用**：来电时能把**微信的通话界面**调到最前面。它本身不显示任何本应用的界面
- 若不给这项权限：锁屏来电时微信界面可能到不了前台，自动接听容易失败（失败时会响铃提醒老人自己点）

### 第四步：锁屏全屏通知（安卓 10+）
- 点击「去开启」→ 在系统「全屏通知」列表里，**同时把「亲情接听助手」和「微信」都打开**
- **作用**：锁屏来电也能点亮屏幕，并让微信通话界面被拉起来

### 额外一步：后台保活（重要！）
- 点击「去设置自启动/后台运行」→ 按手机品牌找到对应设置项
- **作用**：防止系统杀后台，导致来电时 App 没反应

| 品牌 | 设置路径 |
|------|----------|
| **小米 / Redmi** | 设置 → 应用设置 → 授权管理 → 自启动管理 → 开启本应用 |
| **华为 / 荣耀** | 设置 → 应用和服务 → 应用启动管理 → 关闭「自动管理」→ 手动开启「允许自启动」「允许后台活动」 |
| **OPPO / 一加 / realme** | 设置 → 电池 → 应用耗电管理 → 允许完全后台行为 + 允许自启动 |
| **vivo / iQOO** | 设置 → 电池 → 后台耗电管理 → 允许后台高耗电 |
| **三星** | 设置 → 电池 → 后台使用限制 → 不优化本应用 |
| **其他** | 设置 → 应用 → 本应用 → 电池 → 无限制 / 允许后台运行 |

## 使用说明

### 1. 添加家人名单
- 在设置页「称呼」里填老人熟悉的叫法，如「大儿子」「闺女」
- 「微信备注名或手机号」选填，用来更准确地识别来电人
- 点击「＋ 添加到家人名单」
- 勾选「自动接听」的家人来电会自动接通（默认等待 8 秒，可改）

### 2. 试听效果
- 点击「▶ 试听语音播报（模拟张三来电）」
- 手机会播报「张三来视频电话了，请点微信上的接听」，并短震一下
- 这是纯播报演示，不会弹出任何界面，也不会真的拨出电话
- **没听到声音？** 语音播报依赖手机的中文 TTS 引擎。按钮下方的状态卡会直接显示检测结果：
  - 绿色「✓ 语音播报正常」= 一切就绪
  - 红色「✗ …」= 会写明原因（没连上引擎 / 引擎读不出中文）和修复路径，下面还有「检测情况」列出识别到的引擎
  - 可点「↻ 重新检测语音播报」在系统里改完设置后重新判定

### 3. 真实来电时的体验
1. 微信来电 → 手机震动 + 大声播报「XXX 来视频电话了…」
2. 屏幕亮起，显示的是**微信自己的来电界面**（本应用不弹界面）
3. 如果是名单里的家人且勾选了「自动接听」：等待 8 秒后自动接通，老人什么都不用做
4. 其他来电：老人直接在微信界面上点接听即可；播报会一直念到接通或挂断

## 常见问题排查

### Q1：来电时没有语音播报
- 检查「通知使用权」是否已开启
- 打开设置页看语音状态卡：红色说明引擎有问题，按提示去「文字转语音」里选择或安装中文引擎，回来后点「↻ 重新检测语音播报」
- 调高「媒体音量」（播报走的是媒体音量通道）
- 如果手机确实没有可用的中文 TTS，App 会退回循环响系统铃声，来电不会漏
- 老旧机型首次播报可能延迟 1 秒左右（语音引擎需要加载），属正常现象

### Q2：来电时没有自动接听
- 检查「无障碍服务」是否已开启（自动点击的前提）
- 检查「显示在其他应用上层」是否已开启——锁屏时它决定微信界面能否被调到前台
- 检查是否被系统杀后台：参考上文「后台保活」设置
- 若自动点击失败，App 会响铃 + 震动 + 播报「没接上，请自己点一下接听」，此时老人自己点微信的接听即可

### Q3：微信没接通（提示「没接上」）
- 检查「无障碍服务」是否已开启（这是自动点击微信接听键的前提）
- 微信版本更新后界面可能变化，导致自动点击失效。此时播报和铃声会继续提醒老人手动点微信的接听键
- 如果频繁失效，请在 GitHub Issues 反馈你的微信版本号

### Q4：家人来电没有自动接听
- 检查该家人是否已添加到名单，并且勾选了「自动接听」
- 检查设置页的「开启自动接听」总开关是否打开
- 检查「自动接听前等待秒数」是否设置过长（默认 8 秒）

### Q5：App 耗电吗？
- 非常低。通知监听和无障碍服务只在微信来电时工作，平时几乎不耗电
- 如果担心，可在「后台保活」设置里把电池优化设为「不优化」

## 已知限制

1. **仅支持安卓手机**。iPhone（iOS）系统封闭，第三方无法监听微信来电、无法模拟点击接听，因此无法做类似 App。iPhone 用户建议：
   - 开启 设置 → 辅助功能 → 音频/视觉 → LED 闪烁提醒
   - 把微信字体调到最大（设置 → 通用 → 辅助功能 → 更大字体）
   - 家人尽量改用系统电话拨打老人手机
   - 如果条件允许，给老人换一台安卓机使用本方案

2. **微信版本适配**。微信不同版本的通话界面控件 ID 和文字可能不同，自动点击「接听」按钮的准确率取决于微信版本。我们在代码里做了「文字匹配 + 手势点击中心」双重兜底，但无法保证 100% 适配所有版本。

3. **需要一定动手能力**。首次安装需要在老人手机上开启 3~4 个系统权限，建议子女亲自操作或远程视频指导。

4. **家人自动接听有风险**。自动接听意味着任何在名单里且名字匹配的人来电都会自动接通。请确保名单只放真正的家人，并设置合理的等待秒数（建议 ≥5 秒，给老人留出手动挂断的时间）。

## 隐私声明

- **不上传任何数据**。所有功能都在手机本地运行，不联网、不上传通话记录、不上传通讯录。
- **只读取微信通知文本**。通知监听仅用于识别「邀请你视频/语音通话」这类来电通知，提取来电人姓名用于播报和匹配名单。
- **无障碍服务仅用于点击接听**。不会读取微信聊天内容，也不会操作微信的其他功能。

## 技术原理（给开发者看）

```
微信来电
  ├─ 通知监听服务 (NotificationListenerService)
  │     └─ 解析通知里的「来电人 + 通话类型」
  │     └─ 触发 CallSessionManager.startCall()
  │
  └─ 无障碍服务 (AccessibilityService)
        └─ 监听微信窗口状态变化（只监听 com.tencent.mm）
        └─ 发现「接听+挂断」按钮 → 确认是来电界面
        └─ 提供 clickNodeWithText("接听") 自动点击能力
        └─ 每次点击前校验当前窗口属于微信，避免点到别的应用

CallSessionManager（本应用不显示任何界面）
  ├─ TTS 语音播报（循环）
  ├─ 震动
  ├─ 高优先级通知 → 锁屏亮屏 + 一键进微信通话界面
  ├─ 名单命中 + 自动接听开关 → 倒计时后 performAccept()
  │     └─ openIntent.send() 把微信通话界面拉到前台
  │     └─ WeChatClicker.retryClick("接听", 8 次 × 800ms)
  │           └─ 全部失败 → onAcceptFailed()：响铃 + 震动 + 播报提醒
  └─ 超时/接通/挂断 → 清理一切
```
